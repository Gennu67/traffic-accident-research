# Dự đoán mức độ nghiêm trọng của tai nạn giao thông

## 1. Giới thiệu
Đề tài nghiên cứu khả năng ứng dụng Machine Learning để dự đoán mức độ nghiêm trọng của tai nạn giao thông dựa trên các đặc trưng được ghi nhận trong dữ liệu.

## 2. Mục tiêu
- Khảo sát và tiền xử lý dữ liệu tai nạn giao thông.
- Phân tích các đặc trưng có liên quan đến mức độ nghiêm trọng.
- Xây dựng và so sánh các mô hình Machine Learning.
- Đánh giá hiệu quả dự đoán bằng các chỉ số phù hợp.

## 3. Dữ liệu
Bộ dữ liệu dự kiến: US Accidents. Nguồn, phiên bản, phạm vi và các biến sử dụng sẽ được ghi rõ trong quá trình nghiên cứu.

## 4. Công nghệ dự kiến
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook / VS Code
- GitHub

## 5. Cấu trúc dự án
- `docs/`: tài liệu nghiên cứu và báo cáo.
- `notebooks/`: notebook phân tích và xây dựng mô hình.
- `src/`: mã nguồn xử lý dữ liệu và huấn luyện.
- `results/`: kết quả và biểu đồ.
- `models/`: mô hình đã huấn luyện.
